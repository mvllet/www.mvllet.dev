Recently, I ran into issues with the Weather & Stocks tweak caused by an overload on Requis' YQL server (view source code) after Electimons' server went down. To fix this, I recreated and simplified the server for myself using Claude, which worked surprisingly well. If you want to try it out, follow the tutorial below.

To try out my replacement YQL server, simply point Weather & Stocks to it in your settings. Setup takes only a few seconds and is completely safe! Please note: because I replaced some underlying APIs, city IDs have changed. You will need to manually re-add your locations in the Weather app!
  1. Open Settings > Weather And Stocks.
  2. Tap the Server URL field and enter
  3. That's it. The selected default server does not matter.
